# Sprint Documentation

Store all sprint artifacts here (planning, review, retrospective, demos). Create one subfolder per sprint:

- `docs/sprints/sprint-1/`
- `docs/sprints/sprint-2/`
- ...

Each sprint folder should include:
- `planning.md`: goals, scope, backlog items.
- `review.md`: what shipped, demo notes, acceptance.
- `retro.md`: keep / drop / try, action items.

Add new sprints as you progress. Remove this placeholder once real sprint docs are added.
